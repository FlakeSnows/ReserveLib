# Требования к приложению:
#### Минимальные критерии работоспособности
Сборка и запуск
- [x] Приложение собирается без ошибок.
- [x] Секреты не указаны в коде, выбран надежный способ их подтягивать.

Есть README с:
- [x] требованиями (Java версия, Maven/Gradle, Docker)
- [ ] запуск локально средствами Java или в контейнере
- [x] информацией, где хранить секреты
- [x] описанием контракта
- [x] портами и учетными данными для демо.
- [x] Поднята бд.

Здоровье сервиса
- [x] Healthcheck приложения.
- [x] Отдельно виден статус соединения с БД или кидается понятная ошибка при недоступной БД.

Миграции и схема БД
- [ ] бд заполняется приложением без ручного создания таблиц. Схема описана миграциями (Flyway/Liquibase) и накатывается автоматически при старте.
- [x] Есть внешние ключи/constraint там, где нужно по предметной области.

Сквозные пользовательские сценарии (2–3 ключевых)
- [x]  Для каждого сценария есть последовательность REST-запросов (создание → чтение → обновление/удаление).
- [x] Используются корректные методы и статусы: POST 201, GET 200, PUT/PATCH 200/204, DELETE 204.

Валидация и обработка ошибок
- [ ]  Неверные данные → 400 с понятным телом ошибки.
- [x] Отсутствующие ресурсы → 404, невалидная аутентификация/доступ → 401/403 (если есть авторизация).
- [ ] Нет 500 на предсказуемых ошибках пользователя.

Сохранность данных
- [x]  После перезапуска контейнера/приложения ранее созданные сущности сохраняются.

Логи и наблюдаемость
- [ ] Логи содержат время, уровень, краткое описание события/ошибки.
- [ ] Уровень логирования настраивается в конфигурации приложения.

Рекомендуемые (повышенный уровень, за дополнительные баллы)
- [x] Документация API: Swagger/OpenAPI доступен по /swagger-ui или есть актуальная Postman-коллекция с примерами.

Минимальные тесты:
- [ ] 3–5 unit-тестов ключевой бизнес-логики,
- [ ] 1–2 интеграционных теста с БД (H2/Testcontainers).
- [ ] Простая авторизация: регистрация/логин и защищенный эндпоинт, который без токена/сессии возвращает 401/403.
- [ ] Для списков есть базовая фильтрация/пагинация или лимит.
- [ ] Короткая демо-роль: предзаполненный «демо-пользователь» для быстрого входа.
